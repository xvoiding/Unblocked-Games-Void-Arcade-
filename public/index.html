Help

Quick answers and shortcuts.

What is Void Arcade?

A clean hub with games. There are no ads on this site.

How do games load?

Games load directly by default, which is the fastest. If a game is blank, try Proxy in the top bar. Web pages from the browse bar always use the proxy.

A game or site opened blank.

Many big sites can't run inside another page. Try "New tab" in the top bar, or switch to Proxy there.

Do my games save?

Games run through the proxy save inside this site, one slot per game site, and you can back them up in Settings. Games loaded directly save in their own site’s storage, and many browsers block or wipe that, so if a game forgets your progress, turn on "Run games through the proxy" in Settings.

Where are my favorites saved?

On this device, in your browser. Clearing site data or switching devices starts you fresh. You can export a backup in Settings.

Why is some stuff blocked?

Adult and other inappropriate content is blocked on this site.
